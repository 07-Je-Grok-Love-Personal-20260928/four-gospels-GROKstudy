            四福音书是神为祂教会留下的、关于祂儿子耶稣基督的四重见证。本站先从整本圣经与圣约看福音书的位置，再走进时间、故事与地图，然后逐卷深读马太、马可、路加、约翰（背景、为什么写、写了什么、圣经神学、圣约神学、难点、信条对照、应用），再用对观与受难周、教义主题、三大信经与记忆自测把它们收拢。

            🌳 四福音总思维导图

            ✝️ 一位基督 · 四重见证
            • 👑 马太福音 · 天国
              • 王的出身：家谱、降生、东方博士、逃往埃及
              • 王的预备：约翰、受洗、试探、开始传道
              • 第一讲：登山宝训——天国子民的义
              • 十个神迹与第二讲：差遣十二使徒
            • 🦁 马可福音 · 仆人
              • 起头：施洗约翰、受洗、试探
              • 加利利的权能：赶鬼、医病、赦罪、安息日之争
              • 比喻与神迹：“这到底是谁？”
              • 走向外邦地区：喂饱众人、行在海面、门徒仍不明白
            • 🩺 路加福音 · 救恩
              • 降生故事与四首诗歌：神记念祂的圣约
              • 预备：约翰、家谱（追溯到亚当）、试探
              • 加利利事工：拿撒勒宣言、医治、赦罪、门徒
              • 上耶路撒冷的旅程：比喻与门徒教导（路加独有材料集中于此）
            • 🦅 约翰福音 · 信 · 生命
              • 序言：道、光、生命、道成肉身
              • 开始显出荣耀：迦拿、洁净圣殿、尼哥底母、撒玛利亚妇人
              • 节期中的冲突：安息日、生命的粮、住棚节、生来瞎眼的、好牧人
              • 拉撒路复活与时候到了

            ✨ 一节总纲

            约翰的目的句也是四卷福音书共同的目的：认识耶稣是谁（基督、神的儿子），并因信祂的名得生命。
