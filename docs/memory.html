                一、口诀

                马太君王讲天国，
                马可仆人走得急，
                路加人子寻失丧，
                约翰神子赐生命。

                四句对应四卷的画像与钥字：君王·天国 / 仆人·立刻 / 人子·救恩 / 神子·生命。

                人狮牛鹰四活物，
                太可路约次第出。

                耶柔米的传统配对（参结1:10；启4:7）：马太=人、马可=狮、路加=牛、约翰=鹰。这是教会传统的记忆法，不是经文本身的规定（爱任纽的配对略有不同）。

                👑太天国🦁可仆人🩺路救恩🦅约信 · 生命

                七神迹：酒 · 子 · 池 · 饼 · 海 · 眼 · 拉撒路
                七我是：粮 · 光 · 门 · 牧 · 复活 · 道路 · 葡萄树

                约翰福音的两组“七”。前者按出现次序（2；4；5；6；6；9；11 章），后者为 6；8；10；10；11；14；15 章。

                十架七言：赦 · 救 · 托 · 弃 · 渴 · 成 · 交

                父啊赦免他们 → 今日在乐园 → 看你的儿子/母亲 → 为什么离弃我 → 我渴了 → 成了 → 将灵魂交在你手里。

                二、四卷钥字 · 钥节 · 记忆钩

                书卷钥字钥节记忆钩何时 · 何地
                👑 马太福音天国一家谱（王的出身）· 五篇讲论（山·差·比·会·末）· 十余次“应验” · 一个大使命约主后 50–60 年代（圣殿被毁之前） · 巴勒斯坦或叙利亚的安提阿
                🦁 马可福音仆人起头（1:1）→ 立刻！→ “这到底是谁？”（4:41）→ 彼得认信（8:29）→ 三次受难预言 → 百夫长认信（15:39）→ 空坟约主后 55–65 年（多数学者认为是最早成书的福音书） · 罗马
                🩺 路加福音救恩四首诗歌开幕 → 拿撒勒宣言（4:18）→ 定意上耶路撒冷（9:51）→ 旅程中的比喻（失羊·失钱·失子）→ 十字架上的赦免 → 以马忤斯的圣经课约主后 60–62 年（使徒行传结束于保罗在罗马被软禁，路加福音写在其前） · 该撒利亚或罗马（保罗受审期间）
                🦅 约翰福音信 · 生命序言（道·光·生命）→ 七神迹（2–11 章“神迹之书”）→ 七“我是” → 楼上讲论（13–17 章）→ “成了”（19:30）→ 多马认信“我的主，我的神”约主后 85–95 年 · 以弗所

                👑马太福音天国 · 君王

                莫想我来要废掉律法和先知。我来不是要废掉，乃是要成全。

                — 太5:17
                🦁马可福音仆人 · 立刻

                因为人子来，并不是要受人的服事，乃是要服事人，并且要舍命作多人的赎价。

                — 可10:45
                🩺路加福音救恩 · 寻找

                人子来，为要寻找、拯救失丧的人。

                — 路19:10
                🦅约翰福音信 · 生命

                但记这些事要叫你们信耶稣是基督，是神的儿子，并且叫你们信了他，就可以因他的名得生命。

                — 约20:31
                🍷第一个神迹迦拿婚宴变水为酒

                这是耶稣所行的头一件神迹，是在加利利的迦拿行的，显出他的荣耀来；他的门徒就信他了。

                — 约2:11
                🗝️彼得认信凯撒利亚腓立比

                西门•彼得回答说：「你是基督，是永生神的儿子。」

                — 太16:16
                ✝️人子的使命服事与赎价

                因为人子来，并不是要受人的服事，乃是要服事人，并且要舍命作多人的赎价。

                — 可10:45
                🍞生命的粮第一个“我是”

                耶稣说：我就是生命的粮。到我这里来的，必定不饿；信我的，永远不渴。

                — 约6:35
                💡世界的光第二个“我是”

                耶稣又对众人说：「我是世界的光。跟从我的，就不在黑暗里走，必要得着生命的光。」

                — 约8:12
                🐑好牧人为羊舍命

                我是好牧人；好牧人为羊舍命。

                — 约10:11
                🌅复活与生命拉撒路复活

                耶稣对她说：复活在我，生命也在我。信我的人虽然死了，也必复活；

                — 约11:25
                🛤️道路真理生命到父那里去

                耶稣说：我就是道路、真理、生命；若不藉着我，没有人能到父那里去。

                — 约14:6
                🍇真葡萄树住在我里面

                我是葡萄树，你们是枝子。常在我里面的，我也常在他里面，这人就多结果子；因为离了我，你们就不能做甚么。

                — 约15:5
                📜大使命使万民作门徒

                所以，你们要去，使万民作我的门徒，奉父、子、圣灵的名给他们施洗（或译：给他们施洗，归于父、子、圣灵的名）。

                — 太28:19
                🙏主祷文愿你的国降临

                愿你的国降临；愿你的旨意行在地上，如同行在天上。

                — 太6:10
                💛最大的诫命爱神爱人

                耶稣对他说：你要尽心、尽性、尽意爱主―你的神。

                — 太22:37
